和 AI 一起做

三種工作台：網頁、AI IDE、CLI

跟 AI 寫程式，大致有三種工作台：在網頁上聊天、在 AI IDE（例如 Cursor）裡讓它改檔，或在終端機跑 CLI agent（例如 Claude Code）。模型可以是同一個，差別在誰動手改檔、誰跑指令、誰檢查結果。

1同一個需求，誰在動手

假設要在輪值登記網站加一個功能：「首頁顯示本週誰值班」。切換三種工作台，看每一步是你做還是 AI 做。

你做AI 做AI 做、你點頭

AI IDE 多半是拿 VS Code 改出來的，畫面熟悉、看得到每一處改動；CLI agent 沒有漂亮的介面，但它能自己讀整個專案、跑指令、看結果再修，是三者中「自己做完一輪」能力最強的。

2agent 的一輪：讀、想、做、驗

CLI agent 不是一次吐出答案，而是一輪一輪地跑：讀檔、決定、動手、再用指令驗證，看結果決定下一步。但它只能驗證它知道的事。先選專案說明裡有沒有寫主機的 PHP 版本，再一步一步看。
