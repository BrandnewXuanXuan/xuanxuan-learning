快取只認開頭

上一課「帳單」說過，重讀的部分如果還在快取裡，價格只要一折。但快取有個脾氣：它只從開頭逐字比對。前面任何一處改了，後面全部當成新的，重算一次。

1動到哪裡，後面就全部重算

每次送出的內容是照順序排的：最穩定的放前面，最常變的放後面。點下面的動作，看哪些部分還能用快取（綠色）、哪些要重算（紅色）。

這也是 Claude Code 自己的設計原則：時間、檔案變動這類常變的資訊，它不改開頭的系統提示，而是夾在下一則訊息裡送出；MCP 工具平常只放名稱，不在中途增減，就是為了不打破前綴。
