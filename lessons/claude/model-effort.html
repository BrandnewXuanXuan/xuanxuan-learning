模型與思考力度

兩個旋鈕：模型與 effort

用 Claude Code 時，你手上有兩個旋鈕：模型和 effort（思考力度）。它們管的是完全不同的事，搞混了就會轉錯。

1一個管「會什麼」，一個管「多用力」

模型是一組固定的權重，決定它最多能做到多難；你給的提示和 context 只能引導它，改變不了上限。effort 則決定這一次投入多少：讀幾個檔案、跑幾次驗證、多步驟的工作要推進多遠才回頭找你。轉轉看。

4模型的四個等級

官方建議：先從能用的最強模型開始，再用 effort 調成本。強的模型常常用更少的回合做完，算下來每個任務不一定比較貴。點積木看各等級適合什麼：

顧問策略：讓便宜的模型做主要工作，遇到關鍵處再請強模型看一眼計畫或結果。原文的例子是 Sonnet 5 做事、Fable 5 當顧問，成績接近全程用 Fable 5，價格只要 63%。這和「讓 Haiku 收集資料、Opus 設計版面」是同一種分工。
