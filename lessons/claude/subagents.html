Subagent 與角色

派分身去做，只帶結論回來

Subagent（分身）是另一個 Claude，有自己獨立的 context。它在自己的桌上翻遍資料，做完只把一份報告交給你的主對話。

1分身有自己的桌子

按「派出分身」，看兩張桌子各堆了什麼。

主對話
分身
先比較看看：同一份工作，派分身做和自己讀，主對話各剩下什麼。

要記得：分身從零開始，不知道你們剛才聊過什麼，也不會沿用主對話已經打開的 skill。所以派它出去時，要把範圍、要做什麼、報告要長什麼樣子講清楚；需要「沒被先前討論影響」的眼光時，也可以直接說明。

看不懂就回來說 分身 1

3自訂分身：給它多少權限

自訂分身是一個 markdown 檔，放在 .claude/agents/（這個專案用）或 ~/.claude/agents/（所有專案都能用），可以用 /agents 互動建立。裡面寫它的提示、能用哪些工具、要用哪個模型。點選工具，看這個分身能做什麼：

兩個要點：description 寫「什麼時候該派它」，Claude 會照這個自動委派；專門的分身也不要開太多，太多反而會讓自動委派變得不準。會吐出大量輸出的雜事，可以指定 model: haiku，不必用主對話的大模型。

4一次指揮很多個：workflow

任務很大時，Claude Code 可以當場寫一個 workflow（工作流程腳本），一次派出、串起很多個分身。說「用 workflow 做」，或用觸發詞 ultracode 就會開始。幾種常見的編排方式：

代價是 token 用得很兇：每個分身都在花額度。小型的日常工作用一般對話就好，大規模搬遷、深度研究、大量排序這種，才值得拿出 workflow。

看不懂就回來說 分身 4
